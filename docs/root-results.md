## 后续诊断修复的验证边界

审查发现 subprocess 超时时部分输出可能丢失，最后采集日志再次超时可能遮盖原错误。新增 3 项真实子进程回归：保存超时前输出、保留原错误、保留非零退出码；先观察前两项失败，修复后本地 3/3 通过，并加入后续 Root 工作流。上述成功云端运行不包含这项后续修复；未冒称修复版已重跑设备测试。修复只涉及测试证据采集，不更改 APK、保护策略或场景断言。
