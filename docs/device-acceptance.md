仅供自愿参与的测试者在已具备兼容框架的专用测试机执行。不要在日常主力机解锁、刷机或获取 Root；本表不提供这些操作。iPhone 不适用。没有这样的设备时停止在准备阶段，不把模拟器结果填为真机 PASS。

## 准备与记录

- 日期、测试者代号、机型、Android 版本/构建号、CPU 架构、框架及版本：待填。
- 模块版本、三个 APK 的 SHA-256 和来源提交：待填。三个 APK 须来自同次构建；签名不匹配时不要随意卸载其他应用或清数据。
- 仅安装本项目模块、保护组 `dev.antishake.fixture.protectedapp`、对照组 `dev.antishake.fixture.control`。不用真实广告 App。
- 框架作用域只选择保护组，记录设置截图（先裁掉账号、通知、其他应用列表等个人信息）。不要上传设备序列号、IMEI、账号或完整系统日志。
- 模拟器脚本 `ci-root-prepare.sh`、`ci-root-test.py`、`emulator-smoke.py` 不适用于真机；不要修改序列号后强行运行。

## 成对手工验收

每次更改作用域或停用后，强制停止两个靶场，再重开。使用模块首页的探针和广告入口，读取实时结果需点击“刷新探针读数”。仅看到模块已安装不算保护已生效。

| 操作 | 未启用时应观察到 | 保护组启用后应观察到 | 实测/截图编号 |
| --- | --- | --- | --- |
| 分别打开两组探针，轻摇/转动手机 | 两组产生运动事件并进入目标页；若无反应，基线无效，停止判定 | 保护组 Hook=true、运动事件=0 且不跳转；对照组仍跳转 | NOT RUN |
| 改变探针环境光照，刷新读数 | 有光线传感器时两组均有事件 | 两组仍有事件；真机不要求 123 lux；无传感器记 SKIP，不能填 PASS | NOT RUN |
| 普通、延迟按钮广告 | 仅手动关闭 | 保护组自动关闭回内容页 | NOT RUN |
| 缺少关闭按钮广告 | 停留广告页 | 保护组回到已确认的内容父页面 | NOT RUN |
| 正常内容页 | 不自动操作 | 不自动点击、不返回 | NOT RUN |
| 切后台后回前台、旋转屏幕 | 记录原行为 | 保护保持；无意外导航、误点或崩溃 | NOT RUN |
| 重启设备后重开探针 | 记录重启时间 | 保护组仍保护，对照组仍可跳转 | NOT RUN |
| 移除保护组作用域后重开 | — | 原运动行为恢复、Hook=false | NOT RUN |
| 重新加入作用域后重开 | — | 保护重新生效 | NOT RUN |
| 停用模块后重开 | — | 原行为恢复、广告不再自动关闭 | NOT RUN |

不需要猛烈摇晃；握稳设备，出现异常发热、卡顿、崩溃或意外页面立即停止。本模块会影响受保护应用的正常运动功能；不是只屏蔽广告期间的数据。
