# 0.2 双轴代码审查

范围：本地保留的 0.1 源码快照与 0.2 `validation/` 的差异，以及新建的私有仓库文档、许可证说明和工作流。两个独立只读审查分别执行，未将规则合规和需求合规混成一个结论。

## Standards

发现 1 项正确性问题：批量 Hook API 要等所有重载安装完成才返回句柄；若后一个重载失败，前一个已安装的 Hook 不在回滚记录中。现已改为逐个方法安装并立即记录移除回调。新增失败在第二个重载的回归测试，复审通过，无新增阻塞问题。

主观代码异味：无实质性发现。首页使用明确的目标组件和点击时版本检查；CI 最小只读权限、固定 Action 提交、不持久化 Git 凭据、产物七天保留和基线/真实 Hook 区分均符合当前范围。

## Spec

发现 1 项名称不一致：桌面与框架管理器中的模块名仍为旧名，已统一使用 `@string/app_name` 显示“屏蔽摇一摇跳转插件”。未发现其他确定的新增功能缺陷。

未知父页面不点击/不返回/不重试，页面重建不重复启动场景，安装失败回滚记录逐项管理。当前实现不宣称已经优于其他工具。

## 剩余验证关卡

真实 Xposed 安装、失败回滚及广告自动关闭仍需兼容环境测试；JVM/Robolectric 和未启用模块的模拟器基线均不能替代。用户体验对照及法律审查仍未完成。

汇总：Standards 1 项发现已修复，剩余 0；Spec 1 项发现已修复，剩余 0。实际框架行为仍未验收。
